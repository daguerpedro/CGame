## 1.1. Objetivos
- Praticar e desenvolver habilidades em C++.
- Desenvolver habilidades Multi-Plataforma.
- Desenvolver habilidades de projeto de software.
- Desenvolver habilidades e sistemas voltados a jogos.
    - Gerenciamento de memória.
    - Gerenciamento de recursos/assets.
    - Animações.
    - Transições.
    - Networking.
    - Renderização em cenas.
    - Compatibilidade com controles.
    - Portabilidade.
    - Etc.
